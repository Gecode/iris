# Ideas for Iris 1.0

This file collects candidate changes for Iris 1.0 found during the Iris 0.1
work: formats that 0.1 cannot express or expresses awkwardly, surprising 0.1
behavior found while writing the Specification, and what Gecode 7 needs. Each
entry names the problem and where it was found. The 1.0 design reviews this
list (`PLAN.md` §10.1).

## Ideas

### Distinguish missing sections arms from line failures

Iris 0.1 uses `E-LINE-MATCH` for both a failed `line` statement and a
missing required sections arm: Gecode can produce identical complete
diagnostics for them. Give missing sections arms a distinct diagnostic in
Iris 1.0 so adapters can distinguish the failures without parsing the reader
spec. Found while building the [0.1 error registry](../spec/0.1/errors.md).
