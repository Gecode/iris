# 0002. Name spelling

## Status

Accepted, 2026-10-31.

## Context

The language, libraries, tools, and documentation share one name. Its
spelling and the `.iris` extension are settled in
[PLAN.md §3](../../PLAN.md#3-terminology-settle-this-first),
[§9](../../PLAN.md#9-engineering-practices), and
[§12](../../PLAN.md#12-decisions).

## Decision

Write Iris in prose and `iris` in code, commands, package names, and the
`.iris` file extension. Never write the name in all capitals.

## Consequences

Documentation and interfaces use the same spelling. A reader spec uses
the `.iris` extension; the normative document is the Iris Language
Specification, or the Specification, as defined in
[CONTEXT.md](../../CONTEXT.md).
