# 0010. MIT license

## Status

Accepted, 2026-10-31.

## Context

The standalone project needs a license, and the C++ library is designed
for possible adoption by Gecode 7. Gecode uses MIT
([PLAN.md §8.4](../../PLAN.md#84-c-cpp),
[§9](../../PLAN.md#9-engineering-practices),
[§12](../../PLAN.md#12-decisions)).

## Decision

License Iris under MIT, matching Gecode.

## Consequences

The repository's [LICENSE](../../LICENSE) supplies the license terms.
The standalone C++ library meets the license choice in Gecode 7's
integration requirements.
