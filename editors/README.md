# editors

The [TextMate grammar](textmate/README.md) in `textmate/` highlights Iris 0.1
reader specs and includes its scope assertions and snapshot corpus.

This directory will also hold the VS Code extension in `vscode/`, the
JetBrains plugin in `jetbrains/`, the Zed extension in `zed/`, and
configuration snippets for Neovim and Helix in `nvim/` and `helix/`.
`PLAN.md` §8.6, §8.7, and §8.14
describe them; milestone M4b builds them.
