# editors

This directory will hold editor support: the TextMate grammar in
`textmate/`, the VS Code extension in `vscode/`, the JetBrains plugin in
`jetbrains/`, the Zed extension in `zed/`, and configuration snippets for
Neovim and Helix in `nvim/` and `helix/`. `PLAN.md` §8.6, §8.7, and §8.14
describe them; milestone M4b builds them.
