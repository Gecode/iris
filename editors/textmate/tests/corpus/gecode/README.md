# Gecode example reader specs

These six files are byte-for-byte copies of the Rust parser fixtures at
[`rust/iris-syntax/tests/fixtures/gecode/`](../../../../../rust/iris-syntax/tests/fixtures/gecode/).
They contain the `instance_spec` payloads from Gecode commit
`599f977b7855dba2a1a5f67db1892722372067d3`, the Iris 0.1 reference.
The source paths and extraction instructions are in that directory's README.
