# rust

This directory will hold the Cargo workspace of the Rust reference
implementation: the crates `iris-syntax`, `iris-sema`, `iris-core`,
`iris-cli` (the `iris` binary), `iris-lsp`, and `iris-wasm`, published under
the umbrella crate `gecode-iris`. `PLAN.md` §4.2 describes the layers and
§8.1 and §8.7 describe the crates. Milestone M3 builds the core and the CLI,
and milestone M4b builds the language server.
