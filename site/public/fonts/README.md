# Site fonts

These static WOFF2 faces were copied from the Gecode website redesign’s
`fonts/` directory. The site serves them locally; builds need no other checkout.
The font files and license texts are unchanged.

| Family | Weight and style | License |
|---|---|---|
| Raleway | 500, normal and italic | [SIL Open Font License 1.1](Raleway/OFL.txt) |
| Open Sans | 400, normal and italic | [Apache License 2.0](Open_Sans/LICENSE.txt) |
| Roboto Mono | 400, normal and italic | [Apache License 2.0](Roboto_Mono/LICENSE.txt) |
