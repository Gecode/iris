Iris is a declarative language for reading text instance files into named,
typed data. A **reader spec** describes the input format: which values to read,
how to collect them into arrays, and which conditions they must satisfy.
The same reader spec can serve a command-line tool or a host program.

## Read a formula in two minutes

This small [DIMACS CNF](/formats/dimacs-cnf/) file describes a Boolean formula
with three variables and three clauses. A positive number names a variable;
a negative number negates it. Each clause ends with `0`.

<div class="iris-format-library min-w-0">
  <ExamplePane source={example.input.text} href={example.downloads.input} label="Input" exampleKey={key} representation="input" compact />
</div>

The library's reader spec skips comment lines beginning with `c`, captures the
counts from the `p cnf` header, then reads one list per clause. The range checks
that every literal refers to an existing variable. The sentinel `0` ends each
list and is consumed without being stored. `stop "%"` handles the end marker
used by SATLIB files.

<div class="iris-format-library min-w-0">
  <ExamplePane source={format.spec.text} href={example.downloads.spec} label="Reader spec" exampleKey={key} representation="spec" highlighted compact />
</div>

[Build the CLI](/tools/cli/#build-from-source), then run this command from the
repository root. The paths refer to the library's actual files. Choose `--dzn`
to print MiniZinc data:

<div class="iris-format-library min-w-0">
  <ExampleTerminal example={example} formatId={format.id} />
</div>

The result contains the two integer counts and `clause`, a ragged array of integers:
one row of literals per clause, and rows can have different lengths.
The CLI can also print [JSON or a summary](/tools/cli/#read-input).
A [Rust program](/using/rust/) can access the same data through typed accessors.

## Iris and Gecode

Iris grew out of Gecode's instance reader. **Iris 0.1 is the Gecode 6.5.0
language**, with the deliberate differences listed in
[appendix C of the Specification](/specification/0.1/appendix-c-differences/).
Until Gecode's `release-6.5.0` tag exists, the reference is commit
`5e7bbd5c26b0702c6fd652356b2289da0710ac3c`.

Rust is the reference implementation in this repository. Iris 1.0 develops the
language further for Gecode 7; that work is planned. Language versions and
package versions are separate: a Rust package version does not define an Iris
language version.
