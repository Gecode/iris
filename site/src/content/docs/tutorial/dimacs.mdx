A DIMACS CNF file starts with a `p cnf` header. It declares the number of
Boolean variables and clauses. Each clause is a sequence of signed variable
numbers followed by `0`. A negative number denotes a negated variable.

Start with the header, then add the clause body. All commands below run from
the repository root; see the [tutorial setup](/tutorial/#before-you-start).

## Capture the header

A `line` pattern matches a whole remaining line. Literal text checks `p cnf`;
the two captures read integers and store them as `vars` and `clauses`.
The ranges reject negative counts. `gecode.int_max` is a host constant, fixed
at 2147483646, which the library reader uses as the upper bound.

## Add comments and clauses

Declare `comment "c"` at the top level to skip input comments. `#` introduces
a comment in the reader spec itself. These are separate conventions.

`repeat clauses` runs its body exactly that many times. A `list` reads until
its sentinel, consuming the terminating `0` without storing it. The range
`-vars..vars` checks each stored literal against the declared variable count.

<CheckedExample id="dimacs-clauses-spec" title="site/examples/tutorial/dimacs-clauses.iris" />
<CheckedExample id="dimacs-clauses-input" title="site/examples/tutorial/dimacs-clauses.txt" />
<CheckedExample id="dimacs-clauses" />

Each list is one row of `clause`. Repetition adds another array level, so
`clause` has depth 2 and its rows can have different lengths. A clause can
span physical lines: zero ends it. Too few clauses or a missing zero fails
while reading; extra data after the declared clauses also fails.

The Specification defines [comment and stop prefixes](/specification/0.1/04-input/#47-comment-and-stop-prefixes),
[repeats](/specification/0.1/07-structure/#74-repeat-forms-and-termination),
and [lists](/specification/0.1/06-types-and-values/#69-sentinel-and-end-of-line-lists).

## Check an application policy

Suppose your application accepts only nonempty clauses. Add a `check` after
the repeat. In a check, `clause` denotes one record's list, so the condition
runs once per clause. `size(clause)` means the same as `count(clause)`.

## Finish with the library reader

DIMACS itself permits an empty clause, which makes the formula unsatisfiable,
so the library reader leaves out that policy. It adds a format name and
`stop "%"` for the SATLIB trailer. The stop prefix makes the rest of the
input unavailable to reading, including the trailer's final zero.
