The native C++ implementation is planned, without a release date.

Today, use the [CLI](/tools/cli/) to read input into JSON or dzn, or embed
the [Rust API](/using/rust/) in a host program. The
[conformance suite](https://github.com/Gecode/iris/blob/main/conformance/README.md)
contains language-neutral cases shared by implementations.
