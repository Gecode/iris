# spec

This directory will hold the Iris Language Specification, the normative
document for each language version. `0.1/` describes the Gecode 6.5.0
language in Markdown chapters, a formal grammar (`grammar.ebnf`), and the
error code registry (`errors.md`). `1.0/` follows once the 1.0 design starts,
and `schema/` holds JSON Schemas for data, errors, and conformance cases.
`PLAN.md` §6 describes the 0.1 Specification; milestone M1 writes it.
